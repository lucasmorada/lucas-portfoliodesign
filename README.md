# Portfólio profissional — Lucas Dias

Site estático responsivo criado para o Projeto Integrador — Design da Minha Carreira. Não utiliza backend nem banco de dados.

## Como visualizar

1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador. Para uma experiência local mais consistente, você também pode abrir a pasta no VS Code e usar a extensão Live Server.

## Personalizações importantes

### Currículo em PDF

Coloque seu currículo final em `assets/curriculo-lucas-dias.pdf`. Os botões de visualização e download já apontam para esse caminho. O PDF não foi incluído porque precisa ser a versão real e atualizada do currículo.

### Vídeo do pitch

Abra `script.js` e preencha `youtubeUrl` com o link real do vídeo publicado no YouTube. O site cria automaticamente o player incorporado e o link externo. Confira as permissões do vídeo para que o professor possa assistir.

### E-mail

No mesmo arquivo `script.js`, preencha `email` com seu e-mail profissional. O link de contato será ativado automaticamente.

### Links de projetos

Os links de projetos estão apontando para o perfil GitHub como destino inicial. Troque cada link no `index.html` pelo repositório correto e adicione demonstrações ou capturas de tela reais quando disponíveis. Revise as descrições e tecnologias para refletir com precisão o estado atual de cada projeto.

### LinkedIn

Confira o endereço configurado no `index.html` e atualize caso a URL pública do perfil tenha mudado.

## Arquivos

- `index.html`: conteúdo e estrutura das seções.
- `styles.css`: identidade visual, layout responsivo e animações.
- `script.js`: menu móvel, animações de entrada, navegação, currículo, vídeo e e-mail.
- `assets/`: pasta para currículo e imagens dos projetos.

## Antes de entregar

- Adicione o PDF real do currículo.
- Configure o link do pitch no YouTube.
- Atualize o e-mail profissional.
- Confira os links de cada projeto.
- Revise datas, formação, experiências, tecnologias e descrições.
- Teste a navegação em celular e desktop.
