# Lucas Dias | Portfólio Profissional

Portfólio pessoal desenvolvido como parte do **Projeto Integrador — Design da Minha Carreira**, da graduação em Engenharia de Software.

O projeto reúne minha trajetória acadêmica e profissional, competências técnicas, projetos desenvolvidos e planejamento de carreira em uma interface minimalista, responsiva e acessível.

O objetivo é apresentar minha evolução na área de tecnologia, destacando minha experiência com suporte de TI, desenvolvimento web e meu interesse em análise de dados.

## Visão geral

O site foi desenvolvido para centralizar minhas principais informações profissionais em um único lugar, com navegação simples e uma identidade visual própria.

Entre os principais conteúdos estão:

- **Apresentação profissional:** trajetória, formação e interesses na área de tecnologia.
- **Currículo:** acesso para visualizar e baixar o documento em PDF.
- **Projetos:** apresentação de aplicações acadêmicas e pessoais, tecnologias utilizadas e respectivas contribuições.
- **Plano de carreira:** objetivos profissionais de curto, médio e longo prazo.
- **Desenvolvimento contínuo:** competências técnicas e comportamentais que pretendo aprimorar.
- **Posicionamento profissional:** estratégias de networking e presença digital.
- **Pitch profissional:** espaço para apresentação em vídeo hospedado no YouTube.
- **Contato:** acesso aos meus perfis profissionais e canais de comunicação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

O projeto utiliza tecnologias web fundamentais, com foco em organização do código, responsividade, acessibilidade e facilidade de manutenção.

Não requer backend, banco de dados ou autenticação.

## Identidade visual e experiência

A interface segue uma abordagem minimalista e editorial, com tipografia expressiva, paleta neutra, espaçamento consistente e elementos visuais discretos.

O layout foi planejado para diferentes tamanhos de tela, mantendo a legibilidade e a navegação tanto em computadores quanto em dispositivos móveis.

Também foram implementados recursos como navegação por âncoras, menu responsivo e animações sutis de entrada.

## Como visualizar

**Opção 1 — Navegador**

1. Clone ou baixe este repositório.
2. Extraia os arquivos, caso tenha baixado o ZIP.
3. Abra o arquivo `index.html` no navegador.

**Opção 2 — Visual Studio Code**

1. Abra a pasta do projeto no VS Code.
2. Utilize a extensão Live Server, se desejar.
3. Inicie o servidor local e acesse o endereço exibido pela extensão.

## Configuração do conteúdo

Antes de publicar ou entregar o portfólio, atualize os campos que dependem de informações pessoais e materiais definitivos.

### Currículo em PDF

Adicione a versão atualizada do currículo na pasta `assets/` e confira os caminhos definidos nos links de visualização e download do `index.html`.

Utilize o mesmo caminho para ambos os botões, garantindo que eles abram e baixem o documento correto.

### Pitch profissional

Configure a URL do vídeo no `script.js`, conforme a estrutura implementada no projeto. Publique o vídeo no YouTube e verifique se ele está acessível para avaliação.

### Informações de contato

Atualize o e-mail profissional e o endereço público do LinkedIn. Confira também os links para o GitHub.

### Projetos

Revise os nomes, descrições, tecnologias e funcionalidades apresentadas. Substitua os links provisórios pelos repositórios correspondentes e adicione imagens ou demonstrações reais quando disponíveis.

O conteúdo deve representar fielmente o estágio atual de cada projeto.

O site pode ser hospedado gratuitamente pelo GitHub Pages, utilizando o próprio repositório como fonte de publicação.

Após configurar a hospedagem, o portfólio poderá ser acessado por um endereço público e compartilhado em processos seletivos, no LinkedIn e em apresentações acadêmicas.
